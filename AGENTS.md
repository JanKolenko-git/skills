# Agents

What is where, for any agent opening this repository.

- [`SOUL.md`](./SOUL.md): who the agent is and how it writes. Every session loads it in full.
- [`ENGINEERING.md`](./ENGINEERING.md): how the code the skills produce is written. Read once
  before changing code in any repository.
- [`skills/`](./skills): what to do, one skill per task, in `engineering`, `meta` and `beta`.
- [`spec/authoring.md`](./spec/authoring.md): the contract every skill follows;
  [`template/SKILL.md`](./template/SKILL.md) is that contract as a blank.
- [`agents/`](./agents): subagents a skill seats by name.
